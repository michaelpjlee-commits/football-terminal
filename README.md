# Football Terminal

A Premier League 2026/27 dashboard in the style of a trading terminal, with three views:

- **League overview**: table, form, goals, xG, results and fixtures
- **Squads**: a Football Manager-style squad page for any of the 20 Premier League clubs
- **Leagues**: "Leagues in Focus" cards for 12 English, Scottish and European leagues

Open it here: https://michaelpjlee-commits.github.io/football-terminal/

The page is a single static `index.html`. It reads live data from a published Google Sheet that refreshes every night, using data from the official Fantasy Premier League API, Transfermarkt market values and ESPN league tables. Not affiliated with Football Manager, the Premier League, Transfermarkt or ESPN.
